Página única com todos os repositórios públicos de Ana Caroline Lamas, organizados por área.
Cada projeto abre em `/nome-do-projeto` (ex.: `/cwe-cover`, `/aegis`, `/cortador-916`).

## Publicar na Vercel
1. Crie um repositório (ex.: `bancada`) com `index.html` e `vercel.json`.
2. Na Vercel: Add New → Project → importe o repositório → Deploy (sem build).
3. Settings → Domains → adicione o domínio ou subdomínio.

O `vercel.json` faz todas as rotas abrirem o `index.html`, então os links `/nome-do-projeto` funcionam.
Abrindo o arquivo direto no computador, as rotas viram `#/nome-do-projeto`.
